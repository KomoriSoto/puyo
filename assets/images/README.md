# assets/images

このフォルダにゲームで使用する画像ファイルを配置してください。

## 必要なファイル

| ファイル名       | 用途                         |
| ---------------- | ---------------------------- |
| `red.png`        | 赤ぷよの画像                 |
| `blue.png`       | 青ぷよの画像                 |
| `green.png`      | 緑ぷよの画像                 |
| `yellow.png`     | 黄ぷよの画像                 |
| `gray.png`       | おじゃまぷよの画像           |
| `background.png` | ゲーム背景                   |
| `icon.png`       | プレイヤー1のキャラクターアイコン |
| `icon2.png`      | プレイヤー2（CPU）のキャラクターアイコン |
| `rensa.gif`      | 連鎖アニメーション（オプション）         |

> 画像ファイルがない場合、ゲームはキャンバスで描画されたフォールバックのぷよを使用します。
