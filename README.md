# キャラ設定
## **ルナ・ノワール（Luna Noir）**

## 基本プロフィール
- **名前**：ルナ・ノワール（Luna Noir）  
- **年齢**：11歳
- **性格**：  
  - 常に落ち着いた無表情  
  - めったに感歳を表に出さない  
  - 黙っているが、実は毒舌  
  - 好き嫌いがはっきりしており、興味ない相手には完全に塩対応  
  - うさぎのぬいぐるみとだけ会話する（本人いわく「返事してる」）  

## 外見
- 金髪の縦ロール  
- 黄土色（アンバー）の瞳  
- 黒のゴシックロリータ  
- 常に白うさぎのぬいぐるみ「モカ」を抱いている  
- 闇属性
- 表情はほとんど変わらないが、勝利時のみ口元が少し笑う

- 「あんまり騒がしいと、モカが怒るよ」

### ▶ 勝利セリフ

- 「モカがね、あなたは弱いって言ってたよ」  
- 「もう少し強ければ楽しめたのに……残念」  

### ▶ 敗北セリフ
- 「ちょっと……本気出してよ……」  
- 「モカが泣いてる……責任とって」  
- 「負けたのは……たまたま」  

## 背景設定
- 夜の国のお屋敷で暮らすお嬢様  
- 他人への興味は薄く、静かな世界を好む  
- 双子の兄（未登場キャラ）にだけ依存気味  
- ぬいぐるみ「モカ」は兄からのプレゼント  
- モカには“ちょっとした秘密”があり、ストーリー展開で明かされる伏線

# キャラ設定
## 🧬 兄妹の特徴
- **姉：金髪（blonde）・アンバーの瞳**
- **弟：濃い茶髪・アンバー＋緑のオッドアイ**


---

## 🧬 両親の遺伝モデル

### 👨 父
- 髪色：**濃い茶色（Bb）**
  - → 劣性の「金髪遺伝子（b）」を1つ隠し持つ
- 瞳：**アンバー系**
  - 緑の色素遺伝子を潜在的に保持

### 👩 母
- 髪色：**明るい茶色（Bb）**
  - → こちらも金髪遺伝子（b）を1つ持つ
- 瞳：**茶色（brown）**
  - 緑色の遺伝子を劣性または弱い優性として保有

---

## 🧬 姉の遺伝結果
- 髪色：**bb（劣性が揃う） → 金髪**
- 瞳色：メラニン少〜中 → **アンバー（黄土色）**
  - 緑遺伝子は不発現

---

## 🧬 弟の遺伝結果
- 髪色：**Bb → 濃い茶色（優性発現）**
- 瞳：
  - **左目：濃い茶アンバー（メラニン多め）**
  - **右目：緑要素が強く出る → グリーンのオッドアイ**
    - 理由（いずれも自然現象）：
      - メラニン分布の左右差
      - 弱い緑遺伝子の片側発現
      - モザイク（左右で遺伝表現がわずかに違う）
